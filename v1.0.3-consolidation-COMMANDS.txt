Run these from inside your local Hamri repo.

Note: the tests/ folder is already sitting in your working copy with
all four test scripts correctly moved into it (I could write new files
here but not delete the old loose copies at the repo root - see step 5
below to clean those up once you've committed).

1. Make sure your local main is up to date, and clear any stale lock
   file first if you hit one (safe as long as no real git process is
   actually running - check with `ps aux | grep git` if unsure):

   rm -f .git/index.lock
   git checkout main
   git pull origin main

2. Create a new branch and apply the patch (this covers every code/doc
   change plus the three file removals - tests/ is already in place,
   so it isn't part of this patch):

   git checkout -b integration/v1.0.3-consolidation
   git apply v1.0.3-consolidation.patch

3. Stage everything - this picks up the patched files, the three
   removals, and the already-present tests/ folder in one go - then
   commit using the prepared message and push:

   git add -A
   git commit -F v1.0.3-consolidation-commit-message.txt
   git push -u origin integration/v1.0.3-consolidation

4. Open a PR (GitHub UI, or with the gh CLI if you have it installed):

   gh pr create --base main --head integration/v1.0.3-consolidation \
     --title "Merge inline ternary + line-number tracking into v1.0.3; reorganize tests; cleanup" \
     --body-file v1.0.3-consolidation-pr-message.txt

5. Once the PR is merged, move the v1.0.3 tag to the new tip of main:

   git checkout main
   git pull origin main
   git tag -d v1.0.3
   git push origin :refs/tags/v1.0.3
   git tag -a v1.0.3 -m "Hamri v1.0.3" main
   git push origin v1.0.3

6. Clean up leftover scratch files and the now-duplicated loose test
   scripts at the repo root (all safely superseded by tests/ - delete
   whenever convenient, before or after committing):

   rm -f v1.0.3-consolidation.patch v1.0.3-consolidation-commit-message.txt \
         v1.0.3-consolidation-pr-message.txt v1.0.3-consolidation-COMMANDS.txt \
         inline-ternary.patch inline-ternary-commit-message.txt \
         Logger.py.testcopy line_number_full_test.ham line_number_test.ham \
         ternary_test.ham test_v1_0_3.ham

Note: run.py, ROADMAP.md, hamri_api_draft.h, and
hamri_error_diagnostics_draft.md are untracked files already sitting in
your working copy from earlier exploration - left untouched here since
they weren't part of this task; delete them yourself if no longer needed.
